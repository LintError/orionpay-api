# Security Policy

## Supported versions

The latest version of the main branch is supported for security updates.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

If you believe you have found a security issue, report it privately through GitHub's private vulnerability reporting feature if available, or contact the maintainers directly through the repository's private contact channel.

Please include:

- A clear description of the issue.
- Steps to reproduce it.
- Any relevant logs, payloads, or proof-of-concept code.

We will review reports promptly and coordinate a fix.
